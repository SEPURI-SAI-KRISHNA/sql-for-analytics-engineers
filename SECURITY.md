# Security Policy

This repository contains **documentation only** — SQL patterns, explanations, and markdown files. There is no executable code, server, or application.

## Reporting a concern

If you spot sensitive information that has been accidentally committed (e.g. real credentials in an example query), please email the maintainer directly rather than opening a public issue:

**Contact:** [Sepuri Sai Krishna](https://github.com/SEPURI-SAI-KRISHNA) — open a private [GitHub Security Advisory](https://github.com/SEPURI-SAI-KRISHNA/sql-for-analytics-engineers/security/advisories/new) or use the contact details on [sepuri-sai-krishna.pages.dev](https://sepuri-sai-krishna.pages.dev).

For general content corrections (broken SQL, typos), please open a regular issue.
